# Hello World

A first custom app for the P8 / MOY-TIN5 running the regular WatchApps Main environment.

Install **Hello World** from the app store, then open **Hello** in the watch launcher. Tap the screen to increase the greeting count. Press the side button to return to the launcher. The count resets when the app opens; it does not write to flash or run a timer.

## Version 0.02

Explicitly sets both background and text colors for light and dark themes, wakes the display when opened, and draws the greeting before installing touch controls. Uses the built-in bitmap font.
